# 2.7.3 / 67：静态毛玻璃分析卡

分析卡恢复缓存背景位图与深色渐变叠加。渐变为 `0xE62B2D34 → 0xE6202229`，两个端点 alpha 均为 `0xE6`（230/255，约 90.2% 遮盖）。保留 12dp 圆角、`0x32E3E8F0` 描边，以及全部既有入场、内容淡入淡出、高度变化、关闭动画和参数。

背景采集仍排除所有分析卡及其文字。仅对降采样图模糊：采样比例不超过 `1/12`，位图不超过 `160 × 280`；半径 3（七抽头）的横纵可分离均值模糊执行两轮，共四个方向处理。不使用 RenderEffect，也不增加依赖。

首次 attach 和首次 render ENTER 的请求在下一次尺寸就绪的预绘制时合并成一次快照；缓存命中的首次 DIRECT 卡也抓一帧。`lastCapture` 使用 Choreographer 帧标识，仅合并同一宿主窗口同一帧内的明确请求，不进行任何时间间隔判断或定时刷新。快照完成后移除预绘制采集监听。位图与取样坐标均定格；另一张卡的新快照不会修改已经显示的卡片。

滚动引起的宿主重绘、同消息行重新绑定、临时 detach/attach、CONTENT/RINGS/NONE/DIRECT 内容更新不重拍已经完成的快照。新的 ENTER 或显式 `refreshBackdrop()` 允许重拍一次；卡片点击重试、长按消息菜单强制重新分析均已连接该入口。连续请求在下一次采集前合并。新建卡片首次展示会采集它自己的背景。

采集异常返回空快照，并结束本次请求；后续滚动不自动重试。空快照使用 `0xFF2B2D34 → 0xFF202229` 全不透明渐变，显式刷新可再次尝试。绘制成功快照前也垫不透明底色，避免宿主透明区域让未模糊的实时聊天文字透过卡片。

当前分析卡固定使用深色背景与浅色文字，没有浅色分析卡分支。回复抽屉的 ReplyTheme 独立提供浅/深色配色，维持原有底色和对比度。

离线测试验证渐变 alpha 范围 E0–EF、空快照不透明回退、1000 帧滚动/重绑定不重拍、ENTER/显式刷新允许一次采集、失败后不自动重试及同帧共享。真实模糊算法测试覆盖两个方向的细线对比度衰减、宽色块保留以及极小图片边界；宿主绘制接线和既有动画测试同时保留。
